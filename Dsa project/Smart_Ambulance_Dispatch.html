5. Data structures and complexity

Weighted graph — road network

Vertices represent locations and weighted undirected edges represent roads. An adjacency list is manually built using linked edge nodes.

Why: A road network is naturally a graph. Storage: O(V + E). Dijkstra with linear minimum-vertex scan: O(V² + E).

Binary max-heap — emergency priority

Array-backed max-heap manually prioritizes severity; arrival order breaks ties. Insert: O(log N); remove highest: O(log N); cancel/search by ID: O(N).

Singly linked list — ambulance fleet

Each ambulance is stored in a node pointing to the next node. Supports insertion, search, status/location updates, and traversal. Search/update/traversal: O(A); storage: O(A).

Dispatch algorithm
  1. Remove highest-priority emergency.
  2. Calculate routes from available ambulances to incident.
  3. Select reachable ambulance with minimum distance.
  4. If none is available, reinsert the incident so it is not lost.
  5. Mark assigned ambulance BUSY and display route.
  6. On trip completion, update location and mark AVAILABLE.

Nearest ambulance selection: O(A(V² + E)) with this simple Dijkstra.

7. Project report summary

Objective

Build an interactive dispatch simulation that prioritizes emergencies, finds shortest routes in a weighted road network, and assigns the nearest available ambulance using manually implemented data structures.

Problem statement

Incidents have different urgency levels while ambulances are distributed across locations. The system must prioritize incidents, calculate route costs, avoid assigning busy vehicles, and maintain fleet state.

Modules

  • Emergency registration and validation
  • Emergency priority queue using a binary max-heap
  • Road graph and shortest-route finder
  • Ambulance fleet using a singly linked list
  • Dispatch controller, fleet status, and event log

Limitations and future work

  • Fictional locations and fixed road weights; no GPS or live traffic.
  • Fixed-size demo data and no database persistence.
  • Possible extensions: visual map, incident history, hospital selection, and manually implemented min-heap for faster shortest paths.

Conclusion

This project demonstrates how a weighted graph, binary max-heap, and singly linked list can work together on a real-life-inspired problem. The graph models roads and calculates routes, the heap prioritizes incidents, and the linked list maintains ambulance records. It illustrates data-structure operations, edge-case handling, and complexity analysis while remaining an educational prototype—not a real emergency service.
